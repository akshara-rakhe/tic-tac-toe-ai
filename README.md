# Tic Tac Toe with AI (Python)

This project implements a console-based Tic Tac Toe game where a human player competes
against an AI opponent with adjustable difficulty levels. The AI uses the Minimax
algorithm to make intelligent decisions and play optimally.

## AI & Algorithm

The AI is implemented using the Minimax algorithm, a classic decision-making
algorithm from game theory. The algorithm evaluates all possible future game states
and assigns scores based on win, loss, or draw outcomes to choose the best move.

## Difficulty Levels
- Easy: AI plays random valid moves
- Medium: AI alternates between random moves and optimal Minimax moves
- Hard: AI uses full Minimax logic and never loses

## Features

- Human vs AI gameplay
- Three difficulty levels (Easy, Medium, Hard)
- Console-based interface
- Win, loss, and draw detection
- Recursive decision-making using Minimax

## How to Run

1. Clone the repository or download the source file  
2. Run the program
3. Choose the difficulty level when prompted
4. Enter a number between 0 and 8 to make your move
